# Lina TV

Android TV için kişisel IPTV oynatıcısı. [OwnTV](https://github.com/ahXN00/OwnTV) (GPL-3.0) temel alınarak hazırlanmıştır.
Hiçbir kanal ya da içerik içermez; kendi IPTV sağlayıcınızın Xtream / M3U bilgileriyle çalışır.

## Kurulum (TV)
1. TV'de Play Store'dan **Downloader** uygulamasını kurun.
2. Şu adresi girin: `https://github.com/simoku746/L-NA-TV/releases/latest/download/LinaTV.apk`
3. İndirilen dosyayı kurun. Sonraki güncellemeler uygulamanın içinden gelir.
